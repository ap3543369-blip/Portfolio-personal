# Ayush Pandey — Portfolio (React + Vite)

## Setup
1. `npm install`
2. Apni purani `css/style.css` ka poora content `src/css/style.css` me paste karo
3. `image/my.png` ko `public/image/my.png` me rakho
4. Resume PDF ko `public/resume/ayush-pandey-resume.pdf` naam se rakho
5. `npm run dev` — browser me http://localhost:5173 khulega

## Build / Deploy
`npm run build` → `dist/` folder banega (Netlify / Vercel / GitHub Pages par upload kar sakte ho)

## Kya kahan hai
- `src/data/siteData.js` — links, email, phone, resume path, nav items
- `src/data/skills.js` — skills cards
- `src/data/projects.js` — projects (GitHub links yahin "#" se badlo)
- `src/components/` — Navbar, Hero, About, Skills, Projects, Contact, Footer, BackToTop
